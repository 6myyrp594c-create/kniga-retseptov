# Книга рецептов

Личная книга рецептов открывается в браузере, в том числе на iPhone.

https://6myyrp594c-create.github.io/kniga-retseptov/

На iPhone откройте ссылку в Safari, нажмите «Поделиться» и выберите «На экран Домой». Рецепты сохраняются на самом телефоне и в этот репозиторий не попадают. Чтобы перенести их на другое устройство, на первой странице нажмите «Сохранить данные», а там — «Загрузить данные».
